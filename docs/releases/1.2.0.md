# PinShot 1.2.0

- Take and annotate screenshots with Option+A, then copy, save, or pin them. The selected region stays fixed until the capture finishes.
- Customize each corner, padding edge, and background color with live previews and remembered frame settings.
- Draw on pinned screenshots and reopen recent captures from the horizontal history panel. Configure history retention and independent save folders.
- Manage shortcuts, launch at login, Screen Recording, and Accessibility permissions in Settings.
- Use native circular pin controls and glass styling on macOS 26.
- Receive future updates through Sparkle, with automatic checks and downloads plus a **Check for Updates…** menu action. Update packages and the feed are signed with a new PinShot-specific Ed25519 key.

## Installation

Download the DMG for your Mac: **arm64** for Apple Silicon or **x86_64** for Intel. Both builds support macOS 12 or later and are signed with Developer ID and notarized by Apple.

Homebrew users can run `brew update` followed by `brew upgrade --cask --greedy pinshot`.

**Upgrading from 1.1.2 or earlier:** install 1.2.0 once through Homebrew or the DMG. Those versions did not include Sparkle; automatic in-app updates start with 1.2.0.
