# PinShot 1.3.0

- Refreshed settings, menu bar controls, keyboard shortcut recording, permission guidance and launch-at-login controls using MacAppEssentials.
- Added onboarding with real editor and pin previews, Korean and English guidance, and separately recorded Terms acceptance.
- Added bundled Terms of Use and Privacy Policy under Settings → Help & Support.
- Added **Clear History…** in Settings → Features. After confirmation, it removes screenshot history and automatically saved PNG originals, including those in previous save folders. Manually saved copies and open pins remain available. Failed removals can be retried.
- Added optional Sentry crash reports in Settings → General → Diagnostics and onboarding. Reporting is off by default; changes apply after restarting PinShot. Screenshots are not attached, and usage analytics, performance tracking and session replay are disabled.
- Preserved existing capture tools, annotations, screenshot framing, history preferences, save locations and shortcuts.

## Installation and updates

**macOS 13 Ventura or later is now required.** Download **arm64** for Apple Silicon or **x86_64** for Intel. Both apps and DMGs are signed with Developer ID and notarized by Apple.

Existing Sparkle users can use **Check for Updates…**. Homebrew users can run `brew update` and `brew upgrade --cask --greedy pinshot`. Versions 1.1.2 and earlier require a one-time manual or Homebrew upgrade to receive subsequent in-app updates.
